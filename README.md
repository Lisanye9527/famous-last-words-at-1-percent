# Famous Last Words at 1 Percent

A [make.fun](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4) bounty entry: one line of last words a phone says as its battery hits 1 percent — funny, a little heroic, and painfully true to how phones actually fail.

The program holds the line as a fixed constant, checks it against the gate (UTF-8, 1–199 characters, single line), and writes it deterministically to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`.
